# Thaumic Avaritia

面向 **[无尽贪婪：重生 Re:Avaritia](https://github.com/Nova-Committee/Re-Avaritia)** 与 **[Thaumaturge](https://github.com/Leclowndu93150/Thaumaturge)** 的联动 addon 模组，基于 **NeoForge 26.1.2**（Minecraft 26.1.2）构建。

继承了无尽贪婪（Avaritia）与神秘时代 4（Thaumcraft 4）联动内容的灵感，将无尽贪婪的终极材料引入 Thaumaturge 的世界——全新的物品、方块、源质机器、法杖部件与研究。

## 功能特性

### 物品

- **阿卡西记录**（Akashic Record）——一次性授予全部已注册要素的研究点。
- **水晶矩阵杖端**（Crystal Matrix Wand Cap）——法杖 90% Vis 减免；
- **宇宙中子态素杖柄**（Studded Cosmic Neutronium Wand Rod）——无限 Vis 容量。
- **奥法奇点核心**（Arcane Singularity Focus）——复杂度上限无限（`Integer.MAX_VALUE`）的法术核心。
- **下笔如有神之笔与墨**（Infinity Scribing Tools）——永不损坏的笔具。
- **悖论珍珠**（Causality Collapser Pearl）——终望珍珠和悖论物质的结合体，命中引发爆炸、促使裂隙坍缩，并在落点生成节点。

### 方块

- **涌流充能器**（Gushing Charger）——提供无限灵气。
- **宇宙中子态素源质冶炼厂**（Cosmic Neutronium Essentia Smeltery）——无燃料、瞬间冶炼、零污染、零损耗的源质冶炼厂。
- **节点锚**（Node Anchor）——放置在灵气节点上下方以锁定节点状态；上方放置涌流充能器时可提供所有要素各无限（除了无限要素）。
- **万物起源之罐**（Origin Jar）——内含除无限外所有已注册源质无限点。
